# Automation Order

Modpack made by The Peak of Modpacks.

Post-Apocalyptic Economy Pack. The world is Post-Apocalyptic, machine parts can be scavenged from structures. Contracts can be acquired from different factions to obtain new technology for new machines, to manufacture products to sell back to them. Food, weapons, electronics, etc. Some resources can only be acquired through trade. Each faction has their own unique mods so we can work on different ones.
